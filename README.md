# 🌍 GlobeTrekker — Your Ultimate Travel Planner & Blog Platform

GlobeTrekker is a comprehensive web application designed to empower users to effortlessly plan their dream trips and share their adventures with the world through a dynamic blogging platform. Leveraging modern web technologies and AI capabilities, GlobeTrekker simplifies itinerary creation, helps manage trip expenses, and fosters a vibrant community of travelers.

---

## ✨ Features

- ✈️ **AI Trip Planner**: Generate personalized itineraries using Gemini AI.
- 💸 **Expense Insights**: Track and summarize your trip spending.
- 🧾 **Secure User Accounts**: Sign up, log in, and manage your profile.
- 📝 **Travel Blog Platform**: Create and explore community travel stories.
- 📷 **Media Uploads**: Upload blog images via ImageKit.
- 📱 **Responsive UI**: Optimized for all devices.

---

## 🧰 Tech Stack

### Frontend
- React.js, Vite, Tailwind CSS, Redux Toolkit, Shadcn/ui
- Axios, Zod, Sonner, React Router DOM, ImageKit.io SDK

### Backend
- Django, Django REST Framework
- PostgreSQL, SimpleJWT, Whitenoise, Gunicorn

### AI 
- FastAPI, Gemini API, SQLAlchemy, PhiData

### DevOps & Deployment
- Render (deployment), ImageKit.io (media CDN)
